Como funciona

Três passos entre você e a fase 1.

  1. 01

    Escolha o cartucho

  2. 02

    Carrega na aba

    O jogo sobe direto no navegador. Nada de plugin, instalador ou conta obrigatória.

  3. 03

    Jogue do seu jeito

    Setas, Z e X no teclado — ou o controle na própria tela do celular.

Sobre o projeto

Detonado: como isso foi feito.

RetroPlay é uma peça de portfólio. O que está em jogo aqui é o design, a experiência e o código — explicados do jeito que as revistas de dicas explicavam cada fase.

Ficha técnica

Plataforma
Navegador, sem back-end
Linguagens
HTML semântico, CSS, JavaScript puro
Jogos
5 originais, passo fixo a 60 quadros por segundo
Gráficos
Canvas 2D, 256 × 224, image-rendering: pixelated
Rolagem
Motor próprio: IntersectionObserver + position: sticky
Hospedagem
Estática (Vercel ou Netlify)

$ git clone https://github.com/nicolasminetto/retroplay

$ npx serve retroplay

Dica 1

Cinco jogos, zero bibliotecas.

Física, colisão por tiles, inimigos e placar escritos à mão. Um laço com passo fixo de 1/60 s mantém o jogo igual em qualquer monitor, de 60 a 144 Hz.

Dica 2

Sprites feitos de texto.

Cada personagem é uma lista de linhas em que cada letra é uma cor da paleta. As capas dos cartuchos são a primeira tela de cada jogo, desenhada em miniatura — nenhuma imagem externa.

Dica 3

A rolagem é o botão de liga.

Um único valor de progresso, de 0 a 1, comanda o feixe de luz, o chiado, a imagem descendo e os controles. Rolou pra longe? O jogo pausa sozinho.

Dica 4

Acessível por padrão.

As setas só são capturadas durante a partida, para nunca sequestrar a rolagem. Com movimento reduzido, nada se mexe sozinho; cartuchos e controles são botões de verdade, com foco visível.
